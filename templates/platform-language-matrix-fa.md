# Platform Language Matrix — Persian

Status: Canonical
Version: 1.0
Effective: 2026-09-21

## اصل

ایده ثابت می‌ماند؛ بیان برای رسانه عوض می‌شود.

Copy/Paste میان رسانه‌ها ممنوع است.

## LinkedIn

نقش:
مرجعیت فکری مدیریتی و B2B.

لحن:
رسمی زنده، تحلیلی، موضع‌دار.

ساختار ترجیحی:
Hook → Context → Evidence → Reframe → Decision

پیش‌فرض:
- یک ایده اصلی
- پاراگراف‌های کوتاه
- متن قابل استخراج
- نام دقیق مفاهیم
- CTA تصمیمی
- ایموجی پیش‌فرض صفر

برای محتوای Citation-oriented:
- سؤال دقیق را پاسخ دهید.
- واژه کلیدی اصلی در ابتدای متن بیاید.
- هر بخش تا حد ممکن مستقل باشد.
- Long-form و Post مکمل هم باشند.

## Instagram

نقش:
انسانی‌سازی، روایت بصری، Reels و کشف مخاطب جدید.

لحن:
ساده‌تر، سریع‌تر و کمی گفتاری‌تر؛ بدون افت اعتبار.

Caption:
- Hook سریع
- Context کوتاه
- یک Insight
- CTA ساده

Reel:
- جمله اول باید بدون مقدمه وارد مسئله شود.
- حضور واقعی یوسف بر B-roll عمومی اولویت دارد.
- زیرنویس اجباری برای محتوای گفتاری مهم.
- بازنشر صرف محتوای دیگران بدون ارزش جدید ممنوع است.

## X / Twitter

نقش:
آزمایشگاه ایده و سیگنال.

لحن:
فشرده، تیز و قابل نقل.

قالب:
- یک Claim
- یک دلیل یا Evidence
- در Thread، هر پست یک وظیفه

هدف:
تست POV پیش از تبدیل به Master Asset.

## Telegram

نقش:
عمق، یادداشت، Context و جامعه.

لحن:
آرام‌تر و توضیحی‌تر.

ساختار:
- تیتر
- خلاصه
- متن عمیق
- منابع یا پیوند
- سؤال یا اقدام

## Website / Blog

نقش:
Canonical Authority و AI-discoverable archive.

لحن:
دقیق، مستند و پایدار.

ساختار:
- عنوان پرسش‌محور یا مسئله‌محور
- TL;DR
- تعریف مفاهیم
- پاسخ ساختاریافته
- Evidence
- FAQ در صورت نیاز
- تاریخ انتشار و به‌روزرسانی
- نام نویسنده و Entityهای دقیق

## YouTube Long-form

نقش:
Framework، Case Study و تحلیل عمیق.

گویش:
فارسی گفتاری معیار.

ساختار:
Promise → Problem → Framework → Evidence → Example → Decision

اسکریپت نباید به اجرای خشک منجر شود.

## Short Video / Reels / Shorts

نقش:
یک ایده در کمترین زمان.

ساختار:
Hook → One Insight → Proof → Takeaway

یک ویدئو = یک پیام.

## Podcast

نقش:
عمق فکری و شبکه دانشی.

اصل:
پرسش باید پاسخ قابل نقل بسازد.

از سؤال‌های عمومی مانند «از خودتان بگویید» تا حد ممکن عبور شود.

## Media Interview

نقش:
اعتبار بیرونی.

هر پاسخ مهم:
- یک جمله مرکزی
- حداکثر ۳ دلیل
- یک شاهد
- یک محدودیت یا Context

## Comment

نقش:
ساخت رابطه و نشان‌دادن تفکر.

پاسخ خوب باید چیزی به بحث اضافه کند.

تشکر خالی، ایموجی خالی یا بازگویی کامنت ارزش محتوایی ندارد.
