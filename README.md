# MyPRContent — Personal Brand & PR SSOT

این مخزن «مرجع حقیقت واحد» (SSOT) برای برند شخصی، روابط عمومی و محتوای یوسف مذهب در **همه رسانه‌ها** است.

## دامنه

این SSOT فقط برای LinkedIn نیست و همه کانال‌های مرتبط را پوشش می‌دهد:

- LinkedIn
- Instagram
- X / Twitter
- Telegram
- وب‌سایت و وبلاگ شخصی
- رسانه‌های متعلق به آموت
- رسانه‌های تخصصی و خبری
- مصاحبه‌های مکتوب، صوتی و تصویری
- پادکست
- سخنرانی، پنل و وبینار
- ویدئوهای کوتاه و بلند
- یادداشت مهمان، مقاله و PR
- خبرنامه و سایر کانال‌های آینده

## اصل راهبردی

هدف، ساخت «رسانه شخصی یک مدیرعامل» است؛ نه تبدیل حساب‌های شخصی به کانال تبلیغات محصولات.

هویت محتوایی باید حول تجربه واقعی ساخت کسب‌وکار، سازمان، داده، مشتری، ارتباطات، نرم‌افزار و هوش مصنوعی شکل بگیرد.

محصولات و شرکت‌های آموت می‌توانند به‌عنوان شواهد، تجربه و Case Study استفاده شوند؛ اما محتوای شخصی نباید به فروش مستقیم تقلیل پیدا کند.

## مخاطبان اصلی

1. مدیرعامل و مالک کسب‌وکار
2. مدیر فروش و توسعه کسب‌وکار
3. مدیر عملیات
4. مدیر فناوری و تحول دیجیتال
5. مدیر بازاریابی و تجربه مشتری
6. مدیران شرکت‌های نرم‌افزاری و SaaS
7. کارآفرینان و مدیران نسل بعد

## تز محوری اولیه

> مشکل بسیاری از شرکت‌ها، کمبود نرم‌افزار نیست؛ پراکندگی سازمان است.

این تز، نقطه شروع است و با شواهد و تجربه‌های واقعی تکامل می‌یابد.

## قاعده استفاده

پیش از تولید هر محتوای جدید برای هر رسانه:

1. ابتدا `CANONICAL-HEAD.json` بررسی شود.
2. سپس `ssot/MANIFEST.json` خوانده شود.
3. اسناد canonical ارجاع‌شده مبنای تصمیم قرار گیرند.
4. تفاوت لحن و قالب هر کانال اعمال شود؛ اما موضع، ادعا و هویت اصلی ناسازگار نشود.
5. هر ادعای جدید مهم یا تغییر راهبردی ابتدا در SSOT ثبت شود.

## ساختار

- `CANONICAL-HEAD.json` — اشاره‌گر به نسخه جاری
- `ssot/MANIFEST.json` — فهرست اسناد مرجع
- `strategy/brand-core.md` — هویت و جایگاه
- `strategy/channel-system.md` — نقش رسانه‌ها و قواعد بازنشر
- `governance/content-rules.md` — قواعد تولید و کنترل کیفیت
- `content/` — محتوای منتشرشده و برنامه‌ریزی‌شده
