# MyPRContent — Personal Brand & PR SSOT

این مخزن «مرجع حقیقت واحد» برای برند شخصی، روابط عمومی و محتوای یوسف مذهب در همه رسانه‌ها است.

## Strategy v2

جایگاه اصلی:

> **یوسف مذهب؛ متفکر و استراتژیست رشد کسب‌وکار که با آینده‌پژوهی، فناوری و سیستم‌سازی، رشد را سریع‌تر و کم‌ریسک‌تر می‌کند.**

قلمرو اختصاصی:

**Business Growth Architecture — معماری رشد کسب‌وکار**

مدل فکری:

**Signal → Decision → System → Experiment → Scale**

## اصل محوری

هدف، تولید «محتوای بیشتر» نیست.

هدف، ساخت بینش‌هایی است که از داده، تجربه، تصمیم، آزمایش، پیش‌بینی و نوع تفکر یوسف استخراج می‌شوند و به‌سادگی قابل کپی نیستند.

آموت و محصولات آن، از جمله اوج، آوانک، پیامک آموت، سرآور و کولاک، می‌توانند Laboratory و Evidence باشند؛ نه موضوع تبلیغاتی تمام رسانه.
