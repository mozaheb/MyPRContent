# Global Content Trend Radar

Status: Canonical
Version: 1.0
Effective: 2026-09-21
Cadence: Weekly

## هدف

MyPRContent نباید فقط از بازار فارسی یاد بگیرد.

رادار باید الگوهای موفق جهانی را پیش از اشباع شناسایی کند و سپس قابلیت انتقال آن‌ها به مخاطب فارسی و جایگاه یوسف مذهب را بسنجد.

مدل:

**Global Signal → Pattern → Mechanism → Transferability → Persian Adaptation → MyPRContent Experiment**

## اصل

«جهانی» بودن یک محتوا، دلیل تقلید نیست.

هر الگو باید توضیح دهد:
- چرا کار کرده است؟
- در کدام فرهنگ و پلتفرم کار کرده است؟
- آیا مکانیسم آن قابل انتقال است؟
- چه چیزی باید برای فارسی بومی شود؟
- چه بخشی نباید تقلید شود؟

## Trend Classes

### Class A — Structural Shift
تغییری که احتمالاً چند فصل یا چند سال اثر دارد.

نمونه:
افزایش وزن Founder/Executive voice.

### Class B — Emerging Pattern
الگویی که در چند منبع یا منطقه تکرار شده، اما هنوز تثبیت نشده است.

### Class C — Platform Tactic
تکنیک وابسته به یک الگوریتم، قابلیت یا پلتفرم.

### Class D — Meme / Short-lived Trend
موج کوتاه‌عمر.

Class D پیش‌فرض وارد Core Strategy نمی‌شود.
