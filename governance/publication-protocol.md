# Publication & Post-Publication Protocol

Status: Canonical
Version: 1.0
Effective: 2026-09-22

## هدف

هیچ محتوایی نباید فقط «نوشته شود». هر محتوا باید از چرخه تصمیم، انتشار، سنجش و یادگیری عبور کند.

## وضعیت‌ها

- idea
- research
- draft
- review
- approved
- ready-to-publish
- published
- measured
- learned
- archived

وضعیت published فقط زمانی ثبت می‌شود که انتشار واقعی در رسانه تأیید شده باشد.

## Pre-Publish Gate

پیش از انتشار:

1. تطابق با CANONICAL-HEAD بررسی شود.
2. POV اختصاصی وجود داشته باشد.
3. Evidence یا تجربه روشن باشد.
4. تیتر بیشتر از متن وعده ندهد.
5. Fact، Interpretation و Prediction تفکیک شوند.
6. محرمانگی رعایت شود.
7. فارسی طبیعی باشد.
8. CTA از جنس Engagement Bait نباشد.
9. نسخه کانال بومی شده باشد.
10. شناسه و Metadata ثبت شده باشد.

## First-Post Rule

برای نخستین محتوای LinkedIn:
- متن خالص بر کاور ترجیح دارد.
- هدف، معرفی جهان‌بینی است؛ نه معرفی رزومه.
- محصول مستقیم تبلیغ نمی‌شود.
- یک Thesis مرکزی بیان می‌شود.
- CTA باید مخاطب را به یک تصمیم واقعی دعوت کند.

## Review Windows

- T+24h: Early signal
- T+72h: Distribution and conversation quality
- T+7d: Final content review
- T+30d: Search / AI / long-tail check where relevant

## Learning

هر محتوای measured باید حداقل یک Learning داشته باشد:
- Hook learning
- Audience learning
- Format learning
- Topic learning
- CTA learning
- Timing learning

Learning معتبر می‌تواند وارد Pattern Library یا Trend Layer شود.

Core Strategy با یک پست تغییر نمی‌کند.
