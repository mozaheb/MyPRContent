# Persian Headline System

Status: Canonical
Version: 1.0
Effective: 2026-09-21

## اصل

تیتر خوب فارسی فقط «جذاب» نیست.

باید سه کار انجام دهد:

**فهم سریع + تنش ذهنی + وعده معتبر**

## خانواده‌های تیتر

### H1 — تضاد روشن
فرمول:
**X مشکل نیست؛ Y مشکل است.**

نمونه:
«تبلیغات گران نیست؛ تبلیغات کور گران است.»

کاربرد: POV و Reframe.

### H2 — سؤال محدود و مدیریتی
فرمول:
**اگر [نقش/شرایط] باشید، کدام N مورد را بررسی می‌کنید؟**

نمونه:
«اگر مدیرعامل باشید، کدام ۳ عدد را هر روز می‌بینید؟»

کاربرد: Checklist و Decision Content.

### H3 — تغییر باور
فرمول:
**فکر می‌کردیم X؛ اما Y را دیدیم.**

نمونه:
«فکر می‌کردیم مشکل فروش است؛ داده چیز دیگری گفت.»

کاربرد: RETHINK و LAB.

### H4 — پشت تصمیم
فرمول:
**چرا تصمیم گرفتیم X را انجام ندهیم؟**

نمونه:
«چرا تصمیم گرفتیم این قابلیت را نسازیم؟»

کاربرد: DECISION.

### H5 — آزمایش و نتیجه
فرمول:
**X را آزمایش کردیم؛ نتیجه Y شد.**

نتیجه باید واقعی و قابل دفاع باشد.

### H6 — مقایسه غیرمنتظره
فرمول:
**X از Y [نتیجه مشخص] بود.**

فقط وقتی استفاده شود که مقایسه واقعی و مستند باشد.

### H7 — آینده
فرمول:
**تا [زمان]، X دیگر Y نخواهد بود.**

یا:
**سیگنالی که می‌گوید X در حال تغییر است.**

کاربرد: RADAR.

### H8 — پیامد مشخص
فرمول:
**یک [تصمیم/عدد/اشتباه]، [پیامد مشخص] را تغییر داد.**

نمونه:
«یک تغییر ساده، زمان پیگیری فروش را نصف کرد.»

### H9 — حذف راه‌حل رایج
فرمول:
**برای حل X، اول Y را اضافه نکنید.**

کاربرد: سیستم‌سازی و ضدابزارگرایی.

### H10 — سؤال آینده‌ساز
فرمول:
**اگر X از ابتدا وجود داشت، Y چه تغییری می‌کرد؟**

کاربرد: AI، فناوری و Future Thinking.

### H11 — عدد + معنای مدیریتی
فرمول:
**N٪؛ عددی که باید تصمیم X را تغییر دهد.**

کاربرد: DATA.

### H12 — جمله قابل نقل
فرمول:
یک گزاره کوتاه، کامل و موضع‌دار.

نمونه:
«رشد بدون سیستم، فقط یک جهش موقت است.»

## الگوهای مشاهده‌شده در فارسی

در نمونه‌های اخیر محتوای کسب‌وکاری فارسی، این عناصر ظرفیت بیشتری برای توقف مخاطب نشان می‌دهند:

- نقش مشخص مانند مدیرعامل
- عدد محدود
- نتیجه خلاف انتظار
- تصمیم واقعی
- اعتراف به تغییر نظر
- مقایسه ملموس
- پیامد انسانی یا اقتصادی
- سؤال آینده‌محور

این مشاهده، قانون الگوریتمی یا رابطه علت و معلولی نیست و باید با داده MyPRContent آزموده شود.

## سیستم خروجی تیتر

برای هر محتوای مهم، خروجی پیش‌فرض ۶ تیتر داشته باشد:

| کد | مدل |
|---|---|
| A | شفاف و مدیریتی |
| B | تضاد / Contrarian |
| C | پرسشی |
| D | داده‌محور |
| E | تصمیم‌محور |
| F | آینده‌نگر |

AI باید یک گزینه را با عنوان «پیشنهاد اصلی» مشخص کند و دلیل کوتاه بدهد.

## تیتر کاور و Hook پست

این دو الزاماً یکی نیستند.

### Cover Headline
- ۵ تا ۹ واژه
- حداکثر ۳ خط
- یک Claim

### Post Hook
- می‌تواند توضیحی‌تر باشد.
- Keyword و Context کافی داشته باشد.
- وعده کاور را دقیقاً تحویل دهد.

## محدودیت

تیتر نباید:
- وعده‌ای بیشتر از متن بدهد.
- عدد ساختگی داشته باشد.
- اضطراب مصنوعی ایجاد کند.
- از «راز»، «شوکه»، «باور نمی‌کنید» و مشابه آن استفاده کند.
- با حذف Context مخاطب را فریب دهد.
