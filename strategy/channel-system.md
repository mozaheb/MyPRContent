# Channel System

Status: Canonical  
Effective: 2026-09-21

## اصل

یک ایده می‌تواند در چند رسانه منتشر شود؛ اما نباید صرفاً Copy/Paste شود.

هر کانال باید وظیفه مشخص داشته باشد.

| کانال | نقش اصلی |
|---|---|
| LinkedIn | Thought Leadership مدیریتی و B2B |
| Instagram | انسانی‌سازی برند، پشت‌صحنه، روایت بصری و ویدئوی کوتاه |
| X / Twitter | ایده‌های فشرده، مشاهده‌های سریع و گفتگو |
| Telegram | محتوای عمیق‌تر، یادداشت، جمع‌بندی و جامعه |
| وب‌سایت/وبلاگ | مرجع پایدار و قابل جست‌وجو |
| رسانه‌های آموت | پیوند کنترل‌شده برند شخصی با تجربه شرکت |
| رسانه‌های تخصصی/خبری | اعتبار بیرونی، تحلیل و PR |
| پادکست | استدلال بلند، تجربه و گفت‌وگوی عمیق |
| ویدئوی کوتاه | یک مسئله، یک مشاهده، یک نتیجه |
| ویدئوی بلند | آموزش، تحلیل و Case Study |
| سخنرانی/پنل | ایده‌های کلیدی، چارچوب و اعتبار تخصصی |
| خبرنامه | رابطه مستمر و جمع‌بندی فکری |

## مدل توزیع

**Idea → Canonical Claim → Master Asset → Channel Adaptations → Published Evidence → Learning**

یک «ایده مادر» تولید می‌شود و سپس برای هر رسانه بازطراحی می‌شود.

## قواعد

- تیتر و Hook می‌تواند تغییر کند.
- طول محتوا می‌تواند تغییر کند.
- مثال‌ها می‌توانند متناسب با مخاطب تغییر کنند.
- لحن هر کانال می‌تواند متفاوت باشد.
- ادعا، موضع اصلی و واقعیت‌های پایه نباید متناقض شوند.
- هر محتوای مهم منتشرشده باید قابل ردیابی به ایده مادر باشد.
